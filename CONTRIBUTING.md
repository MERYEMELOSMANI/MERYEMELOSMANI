# Contributing Guidelines

Thank you for exploring this repository and my open-source projects!

## How to Collaborate
1. **Fork the Repository**: Create your personal fork to work on proposed changes.
2. **Branch**: Create a descriptive branch (e.g. `feat/improvement` or `fix/typo`).
3. **Commit**: Keep commit messages concise, clear, and focused.
4. **Pull Requests**: Submit PRs with a clear description of the enhancement or bugfix.

## Community & Code of Conduct
- Be respectful, constructive, and collaborative.
- Open an Issue first for substantial architectural discussions.
